| 4 | **`docs/01_裁定记录ADR.md`** | **跨文档冲突裁定 + 5 项待拍板**（并行编写暴露的 19 条问题） |

>
> `docs/` 内按 **前端（`frontend/`，8 功能）｜ 后端（`backend/`，27 功能）｜ 跨端公共（`common/`，5 功能）** 分开，**每个功能一个文件夹**，内含它的 `SPEC-*`（做什么）与 `PLAN-*`（谁/何时/怎么交）。各部分入口是各自的 `README.md`。
