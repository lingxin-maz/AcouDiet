ADR-38: continue the UI work against the delivered mockups -- and look at it first

The previous UI rounds (ADR-24/25/30) drew every conclusion from reading code and
running assertions; no page was ever actually rendered and looked at. That is how
ADR-24's bottom-bar accident shipped: 124 green widget tests, near-blank screen.

So this round starts by making the pages visible: app/tool/visual_capture_test.dart
renders the five pages and all four tabs to 1152x2496 PNGs (the mockups' own size),
straight from `flutter test`. It lives in tool/ and not test/ because pixel
comparison across engines/platforms is exactly the unreliable gate this repo keeps
refusing to build.

Looking at the renders disproved two of my own readings before I acted on them:
there is no seam under the app bar (per-pixel sampling: the gradient is continuous),
and the wall of 「未知类别」 on the records page was my capture harness never calling
loadKnowledgeBase(), not a product defect.

Changes:
  * AcouPageHeader -- the mockups' shared top bar: brand wordmark left, title
    *centred*, page actions right, back arrow when the page was pushed (「我的」 is
    reached from the home bar, so it must not become a dead end).
  * RecordCard -- the kilocalorie moves to the right-hand column the file's own
    header comment had claimed for two rounds while the code rendered it on the left.
  * ProfilePage -- each entry gains the one-line description mockup 9.png draws;
    each is verbatim the clause after the comma of that row's own spoken label.
  * FourDimRadar -- the axis labels stop being a literal TextStyle inside a
    CustomPainter (the only text in the app that no token and no text scale reached).
  * WaveCircle -- a static standing-wave motif while there is no sample at all,
    instead of an empty green disc. Decoration only: it never moves, it is drawn at
    low alpha, it disappears on the first real sample, and the status line beside it
    still says 「当前静默」.

New gates, both negative-controlled: app_bar_test.dart (title centre within 1
logical pixel of the bar centre; root page shows the wordmark, pushed page shows a
working back arrow) and mockup_layout_test.dart (kilocalorie in the right half of
the card; the four idle-motif truth-table cases; the radar label style). Injecting
rtl on the record row and flex:2 on the header's left segment turned all five red
(Expected <1.0, Actual 118.67), and reverting them turned them green.
