## 3. 关键路径（3 人版唯一风险点）

```
D0 环境 + B 技能预演
      │
      ├─→ D2 Kotlin Mel 前端 (P-04) ─→ D3 Mel 对齐 (T-08) ─┐
      │                                                     ├─→ D5 端到端闭环 ★CP2
      └─→ D2 Baseline (T-04) ─→ D3 跨域评估 ★CP1 ──────────┤
                                        └─→ D4 TFLite (T-07)┘
                                                             ↓
                             D6 聚合 (P-06) ─→ D7 行为 (P-07) ─→ D8 闭环
                                                             ↓
                                             D9 三模式 Demo ★CP3 ─→ D10
```

**关键路径 = D0 → `P-04` → `T-08` → `T-07` → `P-05` → D5 闭环 → D9 Demo**
**任何一环延期，优先砍 D6–D8 的增强功能，绝不动 D5 与 D9。**

### 3.1 B 的兜底（Plan-S）

`PLAN-P-04` 必须包含 Plan-S：**若 D2 结束仍未产出 `[128,128]` 数组**（`n_frames = 128`，`ADR-21`），立即放弃自写 Kotlin Mel，改用 **TFLite Task Library `AudioClassifier` + `TensorAudio`**（其内置 Mel 前端默认参数 16 kHz / n_fft 1024 / hop 512 / n_mels 128 与 FF-01~FF-05 一致）。
**Plan-S 的可行性必须在 D0 调研清楚，不得等到 D2 临时找。**
