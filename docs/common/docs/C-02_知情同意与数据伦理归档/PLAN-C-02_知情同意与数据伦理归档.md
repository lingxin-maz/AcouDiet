## 3. 技术方案

**同意书结构（模板骨架说明，正文为 Markdown）**：抬头（项目名 `AcouDiet`、版本 `v1.0`、日期）→ 7 条条款（编号 1–7，逐条与 `SPEC-C-02` §4.1 对应）→ 志愿者声明与手写签名栏 → 项目组签署人栏 → 编号栏（`P0x`）→ 撤回联系方式（项目组内部渠道，**不写入任何网络链接**）。

**归档与校验骨架（PowerShell，≤30 行）**：

```powershell
$root = 'D:\Desktop\Food\docs\compliance\C-02'
# 1) 模板 7 条齐全
(Select-String -Path "$root\consent_form_v1.0.md" -Pattern '^\| [1-7] \|').Count   # 期望 7
# 2) 关键条款在位
Select-String -Path "$root\consent_form_v1.0.md" -Pattern '撤回权','不采集人声对话内容'
# 3) 签署件计数（D1 结束须 >=3）
(Get-ChildItem "$root\scans\*_consent_masked.pdf").Count
# 4) 清单行数 vs 采集目录数
(Select-String -Path "$root\consent_registry.md" -Pattern '^\| P\d\d').Count
(Get-ChildItem 'D:\Desktop\Food\ai\data\raw\P*' -Directory).Count
# 5) 先签后用初筛：签署日期必须早于首次采集日期（人工核对表复核）
Select-String -Path "$root\consent_registry.md" -Pattern 'signedDate|collectedDates'
```

**准入规则交接（给 A）**：`SPEC-T-01` 入库时只接受 `consent_registry.md` 中 `status ∈ {CONSENTED, COLLECTED, IN_DATASET}` 的 `subject_id`；`SPEC-T-02` 划分时剔除 `WITHDRAWN`/`DELETED` 编号。

## 6. 风险与降级

| 风险 | 触发信号 | 降级动作 |
|---|---|---|
| 志愿者不足（**R-7**） | D1 结束签署件 <3 | 启用组内成员自录（**仍需签同意书**，`sourceType=team_member`）；同步下调自采规模并登记 |
| 有人拒签 | 招募当场 | 不采集其数据，不进入清单（状态 `DROPPED`） |
| 打印/扫描条件受限 | D0 无打印条件 | 允许手抄模板现场抄写签署 + 拍照存档；**仍须打码**，并在 `README.md` 记录方式 |
| 已采集数据发现未签（**R-11**） | 归档清点 | 立即删除该 `subject_id` 全部数据、剔除划分、记入 `withdraw_log.md` |
| 志愿者要求撤回 | 收到请求 | 按 `SPEC-C-02` §2.4 删除范围执行并书面确认；已训练权重不重训（§10 #3） |
| 同意书条款被要求增加（如监护人条款） | 评审或志愿者提出 | 走 `SPEC-C-02` §10，变更后新签者用新版（`scopeVersion` 递增），已签者不强制重签 |
