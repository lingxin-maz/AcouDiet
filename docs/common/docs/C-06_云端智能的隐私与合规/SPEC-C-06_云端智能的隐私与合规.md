## 1. 目标与范围
### 1.1 一句话目标
把「云端智能」这件事做成**可当场复核的合规证据链**：一次显式同意、一份可撤回的记录、一条**七类允许 / 七类禁止**的出境规则、两个风味的 `aapt` 证据、以及一份**如实写出失去了什么**的损失声明。

### 1.2 范围内（In Scope）
| # | 内容 | 产物（路径级） |
|---|---|---|
| 1 | **同意门**：告知内容、用户须做的动作、记录方式、撤回方式与撤回后果 | `SPEC-U-07` §4.3 文案；归档副本见 §1.2 第 7 项 |
| 2 | **外发白名单 / 禁止清单**的可验证规则（静态 + 运行时两道） | `tool/check_audio_egress.py --strict`；`app/tool/agent_tests.dart` |

- **不做**云端数据同步、账号体系、埋点上报、崩溃上报（`API-05` §9；§9 已列出）。
- **不做**数据可携带性的实现：`API-05` §11 的缺口在 v2.0 **仍然开放**，本文件只**登记与如实告知**（§10 #1）。
- **不做**数据出境安全评估、标准合同、PIPL 合规审计报批；本文件**不**起草法律文书（§1.3 见 §8 的能力边界）。
- **不做**第三方（DeepSeek）侧的数据留存、二次利用的**审计**：只能引用其公开条款，不能代为承诺（§10 #2）。
- **不做**代下单相关的任何合规路径探索（`FF-26i` 明文禁止，不是待办）。
- **不做** `SPEC-C-01` §7 的权限集合判据本身：本文件只规定「原判据**只适用于 `offline` 风味**」并引用其编号（唯一真源在 `SPEC-C-01`）。

## 2. 功能行为
### 2.1 触发与前置条件
| 项 | 要求 |
|---|---|
| 触发 | `agent` 风味首次进入 `U-07`（第 3 个 Tab）；**不得**在 App 启动时触发 |
| 硬前置 | 无。同意门本身**不需要**任何前置——它必须能在未配 Key、无网络的设备上被完整阅读 |
| 关闭态 | `FF-24` 第 9 条：`agent` 风味首启时联网能力处于关闭态，且**行为等价**于 `offline` 风味 |
| 用户须做的动作 | 阅读 §2.2 的告知内容 → **勾选确认** → 点主按钮。**不得**做成「关闭弹窗即视为同意」（不做预勾选、不做滚动到底自动同意） |
| 一次性 | 同意记录一经写入不再重复弹门；仅由用户在 §2.4 主动撤回后才重新出现 |

### 2.2 主流程（编号步骤）
1. `U-07` 报告未同意 → 渲染同意门；此时 `AgentService.enabled == false`，**零请求**。
2. 逐条告知（**必须全部出现，缺一即判不通过**）：
   ① **外发的是什么**：按 `FF-26d` 的七类字段逐类列举（类别标签、类别 id、进食时间戳、置信度、行为指标、四维分数与评级、聚合计数）；
   ② **不外发的是什么**：按 `FF-26e` 的七类禁止项逐类列举（音频波形、梅尔谱数值、音频文件与缓存路径、设备标识、位置与网络信息、通讯录/日历/媒体库、API Key 之外的其他凭据）；
   ③ **失去什么**：`API-05` §10 的四行对账表，逐行写成用户能读懂的句子（**引用该表，不复制其结论文字**）；
   ④ **成本归谁**：Key 是**用户自己的**、AcouDiet **不内置、不代购、不共享额度**（`FF-26b`）；
   ⑤ **随时可关**：撤回入口位置与后果（§2.4）。
3. 用户勾选确认框（未勾选时主按钮 `enabled == false`）→ 点主按钮。
4. 写同意记录（§4.1）：`scopeVersion` = 当前同意门文案版本号；`consentedAtMs` = 当前时间。
5. 写同意记录的**同一事务/同一步骤**内不得写入任何 Key：Key 由用户在 `U-05` 自行填入（`API-07` §2）。
6. 归档：把已上线的同意门文案**逐字**落到 `records/compliance/C-06/consent_copy_v2.0.md`，并对同意门截图（含按钮与勾选框状态）落到 `gate_screenshot.png`。
7. 每次发版：构建**两个**风味 APK → 各跑一次 `aapt dump badging` → 归档两份输出与两个 `sha256`（§3、§7 #3）。
8. 每次发版：跑 `tool/check_audio_egress.py --strict` 与 `app/tool/agent_tests.dart`，两者**都**必须过。

### 2.3 状态与状态迁移
```dart
/// 用户同意态与凭据态是两个独立维度。
enum AgentConsentState { unconsented, consented, revoked }
enum AgentKeyState { absent, stored }
```
| 同意态 | 事件 | 下一态 | 副作用 |
|---|---|---|---|
| `unconsented` | 用户勾选并确认 | `consented` | 写 §4.1 记录；**不**自动发请求 |
| `consented` | 用户点「关闭云端智能…」 | `revoked` | ① `AgentService.enabled = false`；② 取消进行中的请求；③ **删除**凭据文件（§2.4） |
| `revoked` | 用户重新过同意门 | `consented` | 写新记录（**保留**旧记录的 `revokedAtMs`，不覆盖历史） |
| 任意 | `MaintenanceRepo.clearAllData()`（`API-03` §7） | `unconsented` | 同意记录与凭据文件一并删除（`API-07` §2） |

> 同意态与 Key 态**正交**：`consented` + `absent` = 可联网但无凭据（`U-07` 的 `keyMissing`）；`revoked` + `stored` **不允许**存在（撤回即删 Key，见 §2.4）。

### 2.4 边界条件
- **撤回是否删除已保存的 Key —— 明确回答：删除。** 依据与理由：
  1. **同意是对「出境」的授权，不是对「保存」的授权**。`FF-26c` 说同意是「一次性、可随时关闭」；关闭后 App **不再有任何**被允许的联网用途，此时把一枚可外发的 bearer 凭据留在设备上，**唯一的效果是扩大暴露面**（备份、取证工具、同一台设备的其他应用读取面），却换不回任何功能。
  2. **与既有约束一致**：`FF-26b` 已规定 `clearAllData` 必须删除该文件（`API-07` §2 的判据是清除后 `read() == null`）；撤回若不删，就会出现「一键清除删、单独撤回不删」的两套口径。
  3. **代价必须写在明处**：撤回会**同时删除本机保存的 Key**，用户重新开启时须**重新填入**。这句话是撤回入口的**同屏文案**（`SPEC-U-07` §4.3 的「关闭云端智能并删除本机保存的 Key」），**不得**作为事后提示。
  4. **诚实取舍**：这会牺牲一次便捷性（用户要重新粘贴 Key）。接受它的理由：`FF-26b` 把「不内置、不代购、不共享额度」定为产品立场，Key 的每一次留存都应由一次**当前有效**的同意来正当化。
- **撤回不重写历史记录**：撤回只停止**此后**的出境；已发出的请求无法召回（这是云端的物理事实，必须在同意门文案里写清，**不得**暗示可撤回已发出的数据）。
- **撤回后的对话内存**：清空内存消息（`U-07`），不落盘、不保留。
- **未同意时的等价性**：`agent` 风味的关闭态必须与 `offline` 风味**行为等价**（`FF-24` 第 9 条）——同一条链路、同一份本地语义（`API-05` §8），差别只在 `U-07` 的呈现。
- **Key 的形状校验在写入侧**，**不做在线校验**（`API-07` §2 已裁定：在线校验等于在用户点保存时花他的钱）。
- **任何表面都不得出现明文 Key**：UI 只有 `mask()`（前 3 + `…` + 后 4；长度 < 8 → `****`）；日志、诊断快照、截图、归档一律不得命中 `sk-`（`FF-26b`）。

## 4. 数据契约
### 4.1 同意记录（本文件是它的权威定义；`SPEC-G-02` 为消费方）
| 字段 | 类型 | 单位/值域 | 可空 | 说明 |
|---|---|---|---|---|
| `consentedAtMs` | int64 | epoch 毫秒（UTC，`API-00` §3.2） | 否 | 本次同意时刻 |
| `scopeVersion` | string | 同意门文案版本（如 `v2.0`） | 否 | 文案变更后须重新过门 |
| `gateCopyHash` | string | 文案副本的 `sha256`（hex，64 字符） | 否 | 使「同意的是哪一版文字」可举证 |
| `revokedAtMs` | int64 | 同上 | 是 | 撤回时刻；未撤回为 `null` |
| `keyDeletedOnRevoke` | bool | — | 否 | 撤回时是否已删除凭据；**恒为 `true`**，本字段为可断言留痕 |

> **载体**：与应用私有目录下的凭据同级——`<filesDir>/agent/`，POSIX 模式 `0600`；**不进 SQLite**（`API-03` 不因本域扩表）、**不进 `SharedPreferences`**、**不进 assets**。凭据文件本身的形状以 `API-07` §2 为唯一真源，本文件**不重复定义**。
> **无对应 `docs/common/docs_api/schemas/*.schema.json`**：本域暂不新增 schema 文件；后续若把同意记录并入可机器校验契约，须走 `SPEC-C-03`。

| # | 类别 | 形状约束 |
|---|---|---|
| 1 | `classLabel` | 六类中文名/英文名之一（`FF-19`） |
| 2 | `classId` | 整数 `0..5` |

### 4.3 出境禁止清单（`FF-26e`，`FF-24` 第 8 条的运行时表述）
| # | 禁止项 | 机械判据 |

## 7. 验收标准（可机器判定）
| # | 判据 | 验证方式（命令/测试名） | 通过阈值 |
|---|---|---|---|
| 1 | **静态：音频类型不得出现在网络层** | `python tool/check_audio_egress.py --strict` | 命中数 **== 0**（`app/lib/data/net/**` 不得引用 `Float32List` / `Uint8List` / `Int16List` / `MelFrame` / 音频类型）。**负控（必须已实测变红）**：在 `agent_transport.dart` 里加一行 `Uint8List` 后脚本必须 `exit 1` |
