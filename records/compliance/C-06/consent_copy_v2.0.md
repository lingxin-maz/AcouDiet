## 0. 为什么是"导出"而不是"照散文重打一遍"

`SPEC-C-06` §1.2 第 5 步要求「把**已上线的**同意门文案**逐字**落到 `consent_copy_v2.0.md`」。
按 `SPEC-U-07` §4.3 的散文重新抄一遍会产出**第三份可能漂移的副本** —— 而本目录存在的全部理由，正是防止「同一条主张有两个可以各自漂移的版本」。所以下面的每一段都是从 Dart 常量**直接读出**的，Dart 源码里的相邻字符串字面量（分行书写的那种）在 `UiStrings` 中会拼成一行，下文照拼好的形式给出。

`gateCopyHash`
= `sha256(本文件)`，由 `SPEC-C-06` §4.1 的 `gateCopyHash` 字段消费。**文案变更后必须重新计算并重新过门**（`scopeVersion` 递增）。

## 1. 同意门（`SPEC-C-06` §2.2 要求五条披露**全部**在场）

### 1.1 标题与导语

> **开启云端智能前，请先读这段**
>
> 云端智能默认关闭。开启后，你输入的文字会发送给 DeepSeek，用来生成本轮回复。

对应常量：`agentConsentTitle`、`agentConsentLead`

### 1.2 会发送什么

> **会发送什么**
>
> 本轮对话文本，以及按白名单挑选的本地字段：类别标签、类别 id、进食时间戳、置信度、行为指标、四维分数与评级、聚合计数。

对应常量：`agentConsentSendTitle`、`agentConsentSendBody`；白名单定义见 `SPEC-00` §3.11 `FF-26d`（**七类**）

### 1.3 不会发送什么

> **不会发送什么**
>
> 音频波形、梅尔谱数值、音频文件与缓存路径、设备标识、位置与网络信息、通讯录 / 日历 / 媒体库，以及 API Key 之外的其他凭据。音频永不离开设备。

对应常量：`agentConsentNotSendTitle`、`agentConsentNotSendBody`；禁止清单定义见 `FF-26e`

### 1.4 开启后有什么变化

> **开启后有什么变化**
>
> 「APK 连联网权限都没有」这条证据改由 offline 风味提供；飞行模式下检测、记录、报告与三种演示仍然全部可用，只有本页需要联网；重试、超时与退避只出现在本页，核心链路的本地语义没有变化。

对应常量：`agentConsentLossTitle`、`agentConsentLossBody`

### 1.5 Key 与费用归谁

> **Key 与费用归谁**
>
> Key 必须是你自己的：先在 `platform.deepseek.com` 注册并充值。AcouDiet 不内置 Key、不代购、也不共享额度。Key 只保存在本机，界面上只以掩码显示。

对应常量：`agentConsentCostTitle`、`agentConsentCostBody`；凭据载体见 `FF-26b`

### 1.6 随时可以关掉

> **随时可以关掉**
>
> 设置里有「关闭云端智能并删除本机保存的 Key」：点它会立即停止此后的请求、取消进行中的请求、清空本页会话内容并删除本机保存的 Key。已经发出去的请求无法召回。

对应常量：`agentConsentRevokeTitle`、`agentConsentRevokeBody`（其中 `$agentRevokeAction` = `关闭云端智能并删除本机保存的 Key`，见 §1.7）

### 1.7 勾选框与两个按钮

| 元素 | 逐字文案 | 常量 |
|---|---|---|
| 勾选框 | 我已阅读上述说明，并同意本次数据出境 | `agentConsentCheckbox` |
| 主按钮 | 我已了解，开启云端智能 | `agentConsentConfirm` |
| 次按钮 | 暂不开启 | `agentConsentDecline` |
| 设置页撤回项 | 关闭云端智能并删除本机保存的 Key | `agentRevokeAction` |

**主按钮在勾选框被勾上之前不可点**（`SPEC-U-07` §4.2）；「暂不开启」回到首页，**不写同意记录、不发任何请求**。

## 2. 损失声明的覆盖映射（对 `API-05` §10 的四行）

`SPEC-C-06` §1.2 第 6 项要求「损失声明」覆盖 `API-05` §10 的**四行**。**注意：** 上线的文案把它写成**一段话**而不是四行表格，因为它要在一屏里被读完；下面给出逐项对应，**引用 `API-05` §10 而不复制其文字**。

| `API-05` §10 的代价 | 本版文案在哪里说了它 |
|---|---|
| ① 失去「APK 连联网权限都没有」这条最强隐私证据 | §1.4 第 1 句：「这条证据改由 **offline 风味**提供」 |
| ② 失去飞行模式下的完整功能演示 | §1.4 第 2 句：「飞行模式下检测、记录、报告与三种演示仍然全部可用，只有本页需要联网」 |
| ③ 失去「无后端 = 无一致性/无重试/无冲突」的工程简化 | §1.4 第 3 句：「重试、超时与退避只出现在本页，核心链路的本地语义没有变化」 |
| ④ （`ADR-44` 新增）用户必须自备 API Key | §1.5 全段：「Key 必须是你自己的……不内置 Key、不代购、也不共享额度」 |

> ⚠️ **一处口径更正（`ADR-44` 实施时）**：`SPEC-C-06` §7 #8 原文按「`^\\| ` 行数 **== 4**」判定，即**要求本文件把损失写成四行表格**。但上线的文案是**一段话**，而 §7 #7 又要求本文件与 `UiStrings` **逐字符相等** —— 两条判据互相矛盾，**#7 才是承重的那条**（归档的意义是「用户当时到底看到了什么」）。
> 因此 #8 已改为按**上表的四项覆盖**判定，而不是数表格行数：**一个为了凑格式而把文案改成表格的合规归档，会比它想修的问题更糟**。

## 3. 撤回的确切行为（`SPEC-C-06` §2.4）

点 §1.7 的「关闭云端智能并删除本机保存的 Key」后，**同时**发生四件事：

1. 停止此后的一切请求（同意态置假，闸门关闭）；
2. 取消进行中的请求（`AgentService` 的 `cancelCurrentTurn()`）；
3. 清空本页会话内容（内存中的消息，**不落盘**）；
4. **删除本机保存的 API Key** —— 即 `<filesDir>/agent/credentials.json`。

**为什么撤回要删 Key**：同意授权的**只是出境**，它不构成「保留一个已无用途的 bearer 凭据」的理由。留着一个再也不会被合法使用的密钥，只会扩大泄露面。代价是用户重新开启时要**重新粘贴一次 Key**，这句话就在撤回入口的**同一屏**上（§1.6 的原文），不是事后提示。

**撤回不重写历史**：已经发出的请求**无法召回**。这是云端的物理事实，§1.6 的末句写明了它，**不得**暗示数据可撤回。
